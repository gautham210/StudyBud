High-Yield Core Takeaway

Overlapping subproblems allow caching previously evaluated states. By saving computed results in memory, we flatten otherwise intractable exponential O(2ⁿ) recursion trees directly into streamlined O(n) linear execution runs.

Side-by-Side Python Implementation

PEP 8 Compliant
Top-Down (Memoization)
memoize.py 
def fib_memo(n: int, memo: dict = {}) -> int:
    # 1. Base cases
    if n <= 0: return 0
    if n == 1: return 1
    
    # 2. Check cache
    if n in memo:
        return memo[n]
        
    # 3. Store and return
    memo[n] = fib_memo(n - 1, memo) + \
              fib_memo(n - 2, memo)
    return memo[n]
Bottom-Up (Tabulation)
tabulate.py 
def fib_tab(n: int) -> int:
    # 1. Edge checks
    if n <= 0: return 0
    if n == 1: return 1
    
    # 2. Preallocate DP table
    dp = [0] * (n + 1)
    dp[1] = 1
    
    # 3. Iterative accumulation
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
        
    return dp[n]
